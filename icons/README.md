# App icons

Used by `manifest.webmanifest` (installing the app on a phone's home screen), `apple-touch-icon` and the
browser tab. The open book is from [Noto Emoji](https://github.com/googlefonts/noto-emoji) (`2D/svg/emoji_u1f4d6.svg`),
© Google, Apache License 2.0 (see `img/units/LICENSE`), set on the default theme's colours.

- `icon-192.png`, `icon-512.png`: rounded, for most uses.
- `icon-maskable-512.png`: full-bleed, with the book inside the safe zone, for Android's shaped icons.
- `icon-180.png`: full-bleed, for iPhone (iOS rounds the corners itself).
