Each unit's picture shows its keyword (the word on the unit card, with its spelling pattern highlighted):

| File | Keyword | Emoji |
|---|---|---|
| `u0_sounds.svg` | — | 🔤 |
| `u1_short.svg` | cat | 🐈 |
| `u2_digraphs.svg` | ship | 🚢 |
| `u3_blends.svg` | stop | 🛑 |
| `u4_endings.svg` | boxes | 📦 |
| `u5_silent_e.svg` | cake | 🍰 |
| `u6_teams.svg` | rain | 🌧️ |
| `u7_r_vowels.svg` | car | 🚗 |
| `u8_more_vowels.svg` | moon | 🌙 |
| `u9_longer.svg` | phone | 📞 |

They are shipped with the app so that they look the same on every phone (emoji differ between
Android, iPhone and Windows). If a picture cannot be loaded, the app shows the unit's emoji instead.
